# APPS TRAIN 0201

Given n, how many structurally unique BST's (binary search trees) that store values 1 ... n?

Example:


Input: 3
Output: 5
Explanation:
Given n = 3, there are a total of 5 unique BST's:

   1         3     3      2      1
    \       /     /      / \      \
     3     2     1      1   3      2
    /     /       \                 \
   2     1         2                 3

## Required interface

Implement the following function in Python 3:

```python
def solve(input_str: str) -> str:
```

Notes:
- The function must return the exact expected output string for the given input string.
- Use only Python standard library.
